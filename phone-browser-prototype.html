Direct Bluetooth Mic

Experimental browser test: phone microphone → selected Android media output → Bluetooth mixer.

Status: stopped

Before you test

Pair the phone with the mixer for Bluetooth music first. Start with mixer speakers muted, then raise volume slowly. Keep the phone away from the speakers. Bluetooth delay can be noticeable.

If microphone permission is blocked for this local file, this browser prototype needs to be opened from a secure HTTPS page. This file cannot install itself as a native app.
